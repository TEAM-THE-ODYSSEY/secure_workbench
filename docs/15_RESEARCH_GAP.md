# Research Position

Existing P&ID work demonstrates symbol extraction, structured representations, knowledge graphs, GraphRAG, and agentic querying.

Therefore the project should not claim novelty merely from:
- YOLO + OCR
- P&ID knowledge graphs
- GraphRAG
- LLM agents

A defensible contribution is the integration of:
1. uncertainty-aware multimodal fusion,
2. topology-aware engineering graph construction,
3. plant/revision/approval constrained evidence retrieval,
4. fully local/open-weight inference,
5. evidence-grounded reasoning,
6. explicit validation and human verification.

The contribution must be experimentally demonstrated, not only shown as a block diagram.
